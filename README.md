# Efe Emmanuel Obaro — Portfolio

A React + Vite + Tailwind CSS portfolio site.

## Getting Started

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Stack
- React 18
- Vite 5
- Tailwind CSS 3
- React Router v6

## Pages
- `/` — Main portfolio (Hero, Approach, Skills, Projects, Experience, Blog, Contact)
- `/projects/syncflow` — SyncFlow case study
- `/projects/referchain` — ReferChain case study
